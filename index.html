Cấu hình máy lần đầu

Làm một lần, mất khoảng 3 phút

Cài đặt Region trong Control Panel

Mở Control Panel từ menu Windows.

Chọn Clock and Region → Region.

Ở tab Format, chọn Vietnamese (Vietnam) để ngày giờ hiển thị dạng dd/mm/yyyy.

Cài đặt dấu phân cách trong Excel

Mở Excel → File → Options → Advanced.

Bỏ chọn Use system separators, rồi đặt Decimal separator là . (dấu chấm) và Thousands separator là , (dấu phẩy). Nhớ nhanh: trên chấm, dưới phẩy.

Bật macro và tắt Protected View (bắt buộc)

Vào File → Options → Trust Center → Trust Center Settings.

Tab Macro Settings: chọn dòng cuối Enable VBA macros. Tích thêm "Trust access to the VBA project model" nếu cần.

Tab Protected View: bỏ chọn cả 3 ô để file tải từ mạng không bị khóa.
