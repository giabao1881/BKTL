Hệ Thống Tính Lãi Tự Động

Bộ công cụ Excel hỗ trợ bóc tách và đối chiếu lãi tự động, được xây dựng và duy trì bởi baotg10. Vui lòng thực hiện đủ bước cấu hình trước khi sử dụng để đảm bảo độ chính xác.

Thực hiện một lần duy nhất để đảm bảo file Excel hoạt động chính xác trên máy tính của bạn.

I

Cài đặt Region (Control Panel)

1. Mở Control Panel từ menu Windows.

2. Chọn Clock and Region → Region.

3. Tại tab Format, chọn Vietnamese (Vietnam) để chuẩn hóa định dạng ngày giờ (dd/mm/yyyy).

II

Cài đặt Excel (dấu phân cách)

1. Mở Excel → File → Options → Advanced.

2. Bỏ chọn "Use system separators".
Decimal separator: . (dấu chấm)
Thousands separator: , (dấu phẩy)
(Trên chấm, dưới phẩy)

III

Bật Macro & tắt Protected View (bắt buộc)

1. Vào File → Options → Trust Center → Trust Center Settings...

2. Tab Macro Settings: chọn dòng cuối Enable VBA macros... (tích thêm "Trust access to the VBA project model" nếu cần).

3. Tab Protected View: bỏ chọn cả 3 ô để tắt chế độ bảo vệ khi mở file tải từ mạng (tránh lỗi file bị khóa).
